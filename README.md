# nabless1.github.io

This serves the **Nabless rescue tool** at https://nabless1.github.io/rescue/ :
the page that lets a person use and recover a Nabless Vault without Nabless.

It is the unpacked contents of release `2026-11-25-r5` from
https://github.com/Nabless1/rescue, file for file (`SHA256SUMS.txt` lists every
file's fingerprint). Pre-launch: test networks only, not audited, not signed yet.

A passkey only works at the address it was made on. A passkey made here works
here and nowhere else, so keep using this same address afterwards.
